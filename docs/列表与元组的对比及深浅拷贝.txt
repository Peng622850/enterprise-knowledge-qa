列表与元组的对比及深浅拷贝
在 Python 中，list 和 tuple 是最常用的序列类型，理解它们的区别对编写高效、正确的代码至关重要。list 是动态数组，元素可增删改；tuple 是不可变序列，一旦创建就不能修改。这一差异带来了不同的内存特性与使用场景。由于 tuple 不可变，Python 可以对其做更多内存优化，例如在内部缓存较小的元组，使其创建速度更快，占用内存比列表少。对于不应被修改的数据（如函数返回多个结果、字典的键、配置常量），使用 tuple 更安全且可哈希。

当我们复制包含复合对象的容器时，就会遇到深拷贝与浅拷贝的问题。浅拷贝（copy.copy() 或 list[:]）只复制最外层容器，内部元素仍然是同一对象的引用。深拷贝（copy.deepcopy()）则递归复制所有层次的对象，生成完全独立的新对象。对于纯不可变对象，浅拷贝即可；但若列表或元组中嵌套了可变对象（如列表中存放字典），浅拷贝会带来隐患。

python
import copy
a = [1, 2, [3, 4]]
b = a.copy()             # 浅拷贝，b 的第三个元素与 a 共享
b[2].append(5)
print(a)                 # [1, 2, [3, 4, 5]]，a 也被修改

c = copy.deepcopy(a)     # 深拷贝，完全独立
c[2].append(6)
print(a)                 # 不变
元组虽然不可变，但若其内部元素是可变对象，浅拷贝同样会共享引用。例如 t = ([1,2], [3,4])，浅拷贝出的新元组里的列表仍是原来的对象。此时如需独立，也必须用深拷贝。合理区分两种拷贝能避免难以调试的副作用。通常情况下，处理简单数据用浅拷贝；涉及嵌套可变结构且需要完全隔离时，优先使用 copy.deepcopy。理解可变性与拷贝策略，是掌握 Python 对象模型的关键一步。
